# History

Frozen planning artifacts from earlier phases of the project. Kept for context; not maintained.

- **[spec.md](spec.md)** — original single-group version's product spec. Before Group Group Chat existed, the game had one group collaboratively writing a single message; this document specifies that first version.
- **[implementation-plan.md](implementation-plan.md)** — the build plan for that original single-group game.
- **[group_group_chat_refactor_plan.md](group_group_chat_refactor_plan.md)** — the plan for turning the single-group game into two groups having a conversation. That refactor is what shipped as v0.1.0's Group Group Chat.

For current architecture and how-tos see [CLAUDE.md](../../CLAUDE.md); for the current shipped behavior see [README.md](../../README.md); for release history see [CHANGELOG.md](../../CHANGELOG.md).
